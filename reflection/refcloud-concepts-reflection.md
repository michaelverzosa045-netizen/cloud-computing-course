# Cloud Computing Reflection

As a student, learning about cloud computing helped me realize that I use cloud services every day as a student. The three cloud applications I use most often are Google Drive, Messenger, and Canva. Google Drive helps me store and access my assignments from any device, Messenger allows me to communicate with my classmates and teachers, and Canva makes it easier to create presentations and other school projects. These services make my schoolwork more organized, convenient, and accessible.

All three of these applications are examples of Software as a Service (SaaS) because I use them through a web browser or mobile app without managing the software or servers. They also use the Public Cloud deployment model because they are available to anyone with an internet connection and are maintained by their service providers. I only use the applications while the providers handle the infrastructure, security, and updates.

I also learned that Git and GitHub are important tools for cloud projects. Version control helps track every change made to files, making it easier to restore previous versions, fix mistakes, and keep projects organized. GitHub allows teams to collaborate by sharing code, reviewing updates, and managing changes without overwriting each other's work. These features reduce errors and improve teamwork.

Overall, this lesson helped me understand how cloud computing supports my daily activities and future career in Information Technology. As a student, learning about cloud service models, deployment models, and version control has given me practical knowledge that I can apply in school projects and prepare me for future software and cloud computing careers.
