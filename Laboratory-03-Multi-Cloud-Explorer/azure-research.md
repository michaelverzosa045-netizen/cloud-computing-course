# Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, databases, networking, security, artificial intelligence, and application development. Azure allows organizations to build, deploy, and manage applications using Microsoft's cloud infrastructure.

## Global Infrastructure

Azure has a global infrastructure consisting of geographic regions and availability zones. Azure regions contain datacenters that provide cloud services in different parts of the world. This global infrastructure helps organizations improve application performance, availability, and reliability.

## Cloud Management Console

The Azure portal is a web-based management interface used to create, configure, monitor, and manage Azure resources. Users can manage virtual machines, databases, storage, networking, security, and other cloud services through the portal.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual servers that can run Windows or Linux operating systems and host different applications and workloads.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as documents, images, videos, and backups.

### 3. Azure SQL Database

Azure SQL Database is a managed relational database service based on Microsoft SQL Server technology. It reduces the need to manage database infrastructure manually.

### 4. Azure Virtual Network

Allows Azure resources to communicate securely with each other and with on-premises networks.

## Three Advantages

1. *Microsoft integration* – Azure works closely with Microsoft products such as Windows Server, Microsoft 365, and other Microsoft technologies.
2. *Scalability* – Organizations can increase or decrease cloud resources based on their workloads.
3. *Hybrid cloud support* – Azure provides services that help organizations connect their existing on-premises infrastructure with cloud resources.

## Typical Enterprise Use Cases

Organizations use Azure for hosting websites and applications, running Windows and Linux servers, managing databases, storing data, developing software, implementing artificial intelligence solutions, and supporting hybrid cloud environments. Azure is particularly useful for businesses that already depend heavily on Microsoft technologies.
