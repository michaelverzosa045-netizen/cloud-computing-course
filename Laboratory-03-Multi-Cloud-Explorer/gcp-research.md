# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), also called Google Cloud, is a cloud computing platform developed by Google. It provides services for computing, storage, databases, networking, artificial intelligence, machine learning, and application development. Organizations can use Google Cloud to build, deploy, and manage applications using Google's global cloud infrastructure.

## Global Infrastructure

Google Cloud has a global infrastructure made up of regions and zones. Regions are geographic areas where Google Cloud provides resources, while zones are locations within regions where cloud resources can run. This infrastructure helps organizations deploy applications with good performance, availability, and scalability.

## Cloud Management Console

The Google Cloud Console is a web-based management interface for managing Google Cloud resources and services. Users can create and configure virtual machines, storage, databases, networks, and other cloud resources through the console.

## Four Core Services

### Compute Engine

Compute Engine provides scalable virtual machines that can run applications and workloads on Google's infrastructure.

### Cloud Storage

Cloud Storage is an object storage service used to store files, backups, media, and other types of data.

### Cloud SQL

Cloud SQL is a managed relational database service that supports database systems such as MySQL, PostgreSQL, and SQL Server.

### Google Kubernetes Engine (GKE)

Google Kubernetes Engine is a managed Kubernetes service used to deploy, manage, and scale containerized applications.

## Three Advantages

1. **Strong AI and Machine Learning capabilities** – Google Cloud provides services and tools for developing and deploying AI and machine learning applications.
2. **Kubernetes expertise** – GKE provides a managed Kubernetes environment for containerized applications.
3. **Global infrastructure** – Google Cloud has a global network and infrastructure that supports applications used by customers in different locations.

## Typical Enterprise Use Cases

Enterprises use Google Cloud for web and mobile applications, data analytics, artificial intelligence, machine learning, containerized applications, databases, and large-scale data storage. It is also useful for organizations developing cloud-native applications using Kubernetes and other modern technologies.
